# Aether Chronicles — Rise of the Crystal Dragon

3D Action RPG на C# с использованием MonoGame.

## Особенности

### Игровой процесс
- **WASD** — движение персонажа
- **ЛКМ** — атака (мечом)
- **E** — уворот/перекат (с кратковременным инвинцибилити)
- **F** — использовать зелье лечения
- **I** — открыть инвентарь
- **ПКМ + мышь** — вращение камеры
- **Колёсико** — зум камеры

### Персонаж
- Рыцарь с мечом и щитом
- Система уровней и опыта (XP)
- Инвентарь с оружием, бронёй и зельями
- Авто-сохранение каждые 60 секунд

### Враги
| Тип | HP | Особенность |
|-----|-----|-------------|
| Гоблин-разведчик | 40 | Быстрый, хаотичное движение |
| Орк-воин | 120 | Мощный, умеет делать рывок |
| Тёмный маг | 70 | Стреляет магическими шарами, держит дистанцию |
| Кристальный дракон (Boss) | 800 | 3 фазы, дыхание огнём, летает, в ярости |

### Мир
- Процедурально сгенерированный ландшафт с высотами
- День/ночной цикл (полный цикл = 10 минут)
- 80 деревьев, 40 камней, 5 башен
- Подбираемые предметы на карте

### Предметы
- **Обычные**: Железный меч, Кожаная броня, Зелье здоровья
- **Необычные**: Стальной клинок, Кольчуга
- **Редкие**: Великий Эликсир
- **Легендарные**: Астральный клинок (+35 атаки), Броня из дракона (+50 защиты)

### Квесты
1. **Первая кровь** — убить 5 гоблинов
2. **Угроза орков** — убить 3 орков
3. **Кристальный дракон** — победить босса
4. **Коллекционер зелий** — собрать 3 зелья

### Системы
- Партиклы (кровь, магия, огонь, исцеление, Level Up)
- Экран тряски при получении урона
- Всплывающие числа урона в 3D пространстве
- Мини-карта, HUD с полосами здоровья и XP
- Сохранение/загрузка прогресса

## Сборка

```bash
# Требования: .NET 8.0, MonoGame Content Builder (mgcb)
dotnet build
dotnet run
```

## Технологии
- **C# .NET 8.0**
- **MonoGame 3.8** (DesktopGL)
- Процедуральные 3D модели (без внешних файлов)
- BasicEffect + VertexPositionColorNormal
- Entity-Component архитектура
